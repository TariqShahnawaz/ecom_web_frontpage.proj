# ecom_web_frontpage.proj
First Project Using HTML CSS.

The code builds a fully responsive e-commerce product gallery webpage using only HTML and CSS, without relying on JavaScript. It is designed to be interactive, visually appealing, and user-friendly, making it an ideal example of advanced CSS techniques in practice.

✨ Features

Sticky Header – The navigation bar stays fixed at the top while scrolling, ensuring quick access to the store name, navigation links, search bar, and theme toggle.

Product Filtering – The gallery allows users to filter items by category (All, Electronics, Clothing, Books) using the CSS-only checkbox/radio button hack, eliminating the need for JavaScript.

Responsive Layout – Built with CSS Grid and Flexbox, the design adapts smoothly to different screen sizes, maintaining usability on desktops, tablets, and mobile devices.

Product Cards – Each product is displayed as a stylish card containing:

A badge (e.g., “New”, “Hot”, “Sale”)

A product image

Title and short details

Star ratings

Pricing (with discounted items showing old price using strikethrough)

An “Add to Cart” button

Footer Section – Provides a simple closing element with copyright information.

🎨 Design and Styling

Modern Aesthetic – The webpage uses rounded corners, soft shadows, and gradient backgrounds for a professional yet minimal look.

Typography – Clean and modern fonts from Google Fonts are used, enhancing readability.

Hover Effects – Interactive hover animations are applied to buttons and product cards, making the interface engaging.

Media Queries – Ensure proper scaling and alignment across devices, keeping the design mobile-friendly.

🎞️ Animations

Smooth Transitions – Hover effects on product cards and buttons use transition for smooth color and shadow changes.

Highlighting Active Filters – When a category filter is selected, the button is highlighted to give feedback to the user.

Interactive Buttons – “Add to Cart” buttons have animations like scaling or background-color changes when hovered, improving interactivity.

🌗 Light and Dark Mode

One of the standout features of this code is its theme toggle system.

A hidden checkbox, styled as a toggle button with sun (☀️) and moon (🌙) icons, switches between light and dark modes.

Light Mode – Uses brighter colors, translucent backgrounds, and glassmorphism-inspired effects for a modern, clean interface.

Dark Mode – Switches color variables to darker tones, reducing eye strain and offering a sleek design for users who prefer it.

The toggle is powered entirely by CSS variables, making theme switching smooth and efficient without JavaScript.
